# AeroGlass Nav

Sistema di supporto alla navigazione aerea, Flight Planner e Moving Map con architettura **Map-First** e interfaccia **Cockpit-Friendly** per Microsoft Flight Simulator.

## Caratteristiche principali
- **Map-First UI:** Mappa a tutto schermo con pannelli flottanti in stile glassmorphism e controlli contestuali.
- **Omni-Search:** Ricerca rapida unificata per aeroporti, radioassistenze (VOR/NDB) e waypoint.
- **Profilo Altitudinale Interattivo:** Pannello inferiore a scomparsa con terreno, MSA e punti TOC/TOD.
- **Integrazione SimConnect:** Telemetria e posizione aeromobile in tempo reale.
